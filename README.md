# tkinter_avatar_maker
Project Context: This was a school finals project for Computer Programming Concepts—applying learning concepts such as Tkinter basics, object-oriented programming concepts, file-handling, exception-handling, etc.

Program Description: An avatar maker created in Python using Tkinter for its GUI and JSON to store each instance of saved avatar. It allows users to create customizable avatar portraits by selecting different visual elements such as hair, eyes, mouth, etc.

Other Notes:
- This application uses PIP module (comes pre-installed with Python versions 3.4 and later). If the library is not yet installed for you, please install: [ pip install Pillow ]

Downloading Instructions:
- Download all files and folders in a zip file and open the entire folder in your IDE rather than opening the individual script files.
- Run the main script: ' tk_main.py '
- Please do not delete a file, or change directories for folders "asset_icons", "assets", and "resources" as the program will not run without them.
